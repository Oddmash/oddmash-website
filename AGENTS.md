# Oddmash organization website

Follow Oddmash organization agreements and shared product, brand, accessibility, web delivery, privacy, QA and Git workflow guidance. The public static website is deployed through GitHub Pages. Keep preview builds noindex; the Pages build uses the approved public origin. No tracking or unpublished project material in the deployed artifact. Position Oddmash as Developer Experience Lab. Lead with public products and developer problems, not the maintainer or agents. Verify supported locale switching, project links, Korean editorial wrapping, share feedback, responsive layout and keyboard access before release.

## Agent contribution attribution

Follow the [Oddmash agent attribution convention](https://github.com/Oddmash/.github/blob/main/AGENTS.md#agent-contribution-attribution). When a commit materially incorporates a verified finding or recommendation from Reviewer, Impact, Triage, QA, Release, Docs, or Architect, append the canonical `Co-authored-by` trailer for each actual contributing GitHub account. Deduplicate trailers, preserve human authorship and record the source role or discussion for shared identities. Do not credit unused advice or rewrite published history.

## Branch workflow

This organization website is a main-only repository. Create focused topic branches from `main` and target `main` directly. Do not create or use `develop`. Keep issue linkage, required CI, review, normal merge commits, and GitHub Pages deployment from `main`.
