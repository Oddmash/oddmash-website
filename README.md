# Oddmash

Developer Experience Lab. A localized showcase of our public developer tools, working principles, and contribution paths in English, Korean, Japanese and Simplified Chinese.

![Oddmash logo](public/assets/oddmash-logo.png)

[Visit the website](https://oddmash.github.io/oddmash-website/)

- [Juliya (formerly Kowrap)](https://github.com/Oddmash/kowrap)
- [Oddmash UI](https://github.com/Oddmash/oddmash-ui)
- [Interaction Inspector](https://github.com/Oddmash/interaction-inspector)
- [Boundra](https://github.com/Oddmash/boundra)

Juliya is the public product brand. The website retains the historical Korean comparison and screenshot from the pinned `@oddmash/kowrap@0.3.0` release; current multilingual documentation is hosted on the product site.

The site also illustrates how focused changes move from issues and implementation through checks, review, maintainer decisions and deployment. See [development and launch checks](CONTRIBUTING.md).
